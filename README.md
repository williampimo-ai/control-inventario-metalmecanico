# Sistema de Control de Inventarios en Tiempo Real - Sector Metalmecánico

## 📝 Descripción del Proyecto
Este proyecto presenta la propuesta técnica y arquitectónica para la digitalización del control de inventarios de una empresa manufacturera de herrajes y pasatapas para transformadores. Reemplaza el flujo manual en papel por una arquitectura desacoplada basada en una API REST y un frontend interactivo.

## 🚀 Tecnologías Propuestas
* **Frontend:** ReactJS (con Hooks y Context API para la gestión de estados globales y alertas de stock).
* **Backend:** API REST documentada interactivamente con **Swagger**.
* **Gestión de Datos:** Base de datos relacional para asegurar la consistencia del stock en los procesos de producción.
* **Hardware:** Integración con lectores de código de barras para dispositivos móviles con certificación IP65 o superior.

## 📂 Contenido del Repositorio
* `/frontend`: Código fuente de la interfaz de usuario desarrollada en React.
* `/backend`: Lógica de servidores, endpoints REST y contratos de Swagger.
* `Propuesta_Proyecto_Informatico.pdf`: Documento formal de la propuesta (siguiendo normas APA 7).
